# Voca Bettle

영단어의 뜻을 보고 정답 단어를 선택하는 **웹 기반 영단어 퀴즈 게임**입니다. 
난이도에 따라 문제를 선택할 수 있으며, 제한 시간 안에 최대한 많은 문제를 맞혀 높은 점수와 재화를 획득할 수 있습니다.

---

## 실행 환경

### 배포 버전

Render에 배포된 버전은 별도의 개발 환경을 설치하지 않아도 웹 브라우저에서 실행할 수 있습니다.

| 항목 | 환경 |
|---|---|
| 실행 환경 | 웹 브라우저 |
| 배포 서버 | Render |
| 프론트엔드 | HTML / CSS / JavaScript |
| 데이터 형식 | JSON |

Chrome, Edge 등의 최신 웹 브라우저에서 실행할 수 있습니다.

### 로컬 개발 환경

프로젝트의 소스 코드를 수정하거나 로컬에서 테스트하려는 경우 다음 환경이 필요합니다.


| 항목 | 사용 기술 |

## 실행 방법

### 배포된 웹 페이지에서 실행

본 프로젝트는 Render를 이용하여 웹 서버에 배포되어 있으므로 별도의 개발 환경을 구성하지 않아도 웹 브라우저에서 바로 실행할 수 있습니다.

1. Chrome 등의 웹 브라우저를 실행합니다.
2. 아래 링크에 접속합니다.
**[Voca Battle 실행하기](https://vocabattleproject.onrender.com/)**
※ Render 배포 환경의 특성상 웹 페이지를 처음 실행하거나 장시간 사용하지 않은 후 다시 접속하는 경우, 서버가 활성화되는 데 다소 시간이 소요될 수 있습니다.

---

### 로컬 환경에서 실행

로컬 환경에서 실행을 원할 경우 로컬 환경에서도 실행이 가능합니다.

#### 실행 방법

1. 먼저 프로젝트 폴더를 Vicual Studio Code 등으로 엽니다. 
2. 터미널에서 프로젝트 폴더로 이동한 후 다음 명령어를 실행합니다.
node server.js
3. 서버가 정상적으로 실행되면 다음과 같은 메시지가 표시됩니다.
Voca Battle 서버 실행: http://localhost:3000
4. 이후 웹 브라우저에서 다음 주소로 접속합니다.
http://localhost:3000
5. 게임 화면이 표시되면 정상적으로 실행된 것입니다.
6. 로컬 서버를 종료하려면 터미널에서 다음 키를 입력합니다.
Ctrl + C

## 주요 기능

### ① 난이도 선택

게임 시작 전에 다음 세 가지 난이도 중 하나를 선택할 수 있습니다.

- 초급
- 중급
- 고급

선택한 난이도에 해당하는 단어를 이용하여 문제가 출제됩니다.

### ② 영단어 퀴즈

화면에 영어 단어의 뜻이 문제로 표시되며, 4개의 영어 단어 중 정답을 선택합니다.

- 정답 1개
- 오답 3개
- 선택지는 매 문제마다 무작위 배치

### ③ 제한 시간

각 문제마다 제한 시간이 주어집니다.

문제를 연속 10문제이상 맞히면 이후 문제의 제한 시간 0.5초씩 감소합니다.

단, 설정된 최소 제한 시간(3초) 이하로는 감소하지 않습니다.

### ④ 점수 및 콤보

문제를 맞힐 때마다 점수가 1점 증가합니다.

연속으로 정답을 맞히면 콤보가 증가하며, 콤보에 따라 다음 문제의 제한 시간이 감소합니다.

### ⑤ 게임 종료

다음과 같은 경우 게임이 종료됩니다.

- 오답을 선택한 경우
- 제한 시간이 0초가 된 경우
- 해당 난이도의 모든 문제가 출제된 경우

### ⑥ 재화 획득

게임 종료 후 점수와 난이도에 따라 재화를 획득합니다.

| 난이도 | 재화 획득량 |
|---|---:|
| 초급 | 점수 × 1 |
| 중급 | 점수 × 2 |
| 고급 | 점수 × 3 |

### ⑦ 최고 점수 저장

게임 종료 후 현재 점수와 기존 최고 점수를 비교하여 더 높은 점수를 최고 점수로 저장합니다.

### ⑧ 랭킹

게임 기록을 저장하고 점수를 기준으로 정렬하여 랭킹을 표시합니다.

### ⑨ 사용자 데이터 저장

다음 사용자 데이터를 JSON 파일에 저장합니다.

- 보유 재화
- 최고 점수
- 게임 랭킹 기록
